## 🏢 Office Project

### 📊 Automated Financial Presentation Generator (RAG)
An enterprise-grade Retrieval-Augmented Generation (RAG) application designed for a finance company to automatically generate PowerPoint presentations (PPTs) from financial reports and documents.

- **Framework & Orchestration:** LangChain (LangChain Expression Language - LCEL)
- **LLM & Embeddings:** OpenAI `gpt-4o` and `text-embedding-3-small`
- **Backend API:** FastAPI
- **Search & Retrieval:** Azure AI Search
- **Data Storage:** Azure Storage (managed via Azure Storage Explorer)
- **Database Backup:** PostgreSQL (backs up responses for every query to ensure reliability)
